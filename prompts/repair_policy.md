# 本地优先的迭代规则

每轮保存输入摘要、使用的程序版本、模型身份、问题清单、采取的措施与复测结果。失败也保留，不能只展示最好的一页。

1. 保持原稿只读。PPT 参考仅用于评估；PDF 转换器不得读取参考 PPT 的内容来“补答案”。
2. 先解析原生文字、图片、路径、绘制顺序、蒙版、裁剪和渐变。
3. 对版面问题先修坐标、字体、透明度、绘制组或蒙版；对图片中的文字先本地 OCR；对对象边缘先本地颜色或 SAM 分割；对简单背景先本地重建。
4. 相同本地问题失败后写明证据与原因，调整方法；不得重复空跑。环境缺失先修环境，不能当成模型升级理由。
5. 本地确实无法完成时，只发必要裁剪与上下文。必须记录页码、区域、原因、模型、预算预留及返回结果。累计外部接口试验不得超过 5 美元。
6. 模型建议只能形成候选操作。经结构、坐标、预算与素材归属检查后，由本地程序执行有限动作；不执行模型生成的命令。
7. 视觉还原、文字可编辑、对象独立、移动残影、推断补全分别判定。任一必要项未通过，本页不能记为完美。
8. 所有小标签、页脚、导航与图内文字逐项确认。自动 OCR 低于接收阈值时不删除原字；人工框选校正可以生成真实文本框，但应记录为人工修订，不能算作自动恢复成绩。
9. 字体家族、粗体、斜体、字号和字间距分别保留。必须在 PowerPoint 保存并重新打开验证。字号存储以 0.01 点为精度比较，不能用二进制浮点严格相等判失败。
10. OCR 漏掉首尾标点时，只能提出有限候选，再用原字形证据验证；不能凭语义自动补字。候选不通过时保留原图，并显示仍未恢复，不能以文本框数量代替全部可编辑验收。
11. 自动字形校准必须保护已手工修改或锁定的对象。放大字号后应同时检查网页文本框裁切与导出外观，不能只检查字体属性存在。
12. 移开文字时，同时检查原字、阴影、描边和抗锯齿残块。阴影只有通过字形匹配才可关联；清空旧字但破坏底板仍判失败。在相同文字和对象可编辑覆盖下，新方案实际降分时撤回默认实现，保留失败证据。新增原生文字后若字体外观变差，必须保留对照、标为需校正并继续修字体，不能用退回图片来冒充文字验收通过；视觉目标不因此降低。
13. 人物、照片和图标必须核对完整语义对象，裤腿等碎片不能计为人物分割成功。自动结果、人工框与点提示的校正结果分别报告；移动后补全涂抹也必须单独判失败。
14. 透明素材只以alpha合成后的可见图像作为模型输入，不识别隐藏RGB。视觉评估固定字体会话、渲染器与输入版本；代表页成绩不得代替全稿验收。
15. 白色文字有彩色描边时，不能只用整幅平均亮度选择识别底色；检查可见字芯。混合深浅文字使用本地对照底交叉核对并按位置去重，保留源填充色和透明度。不能靠降低置信度门槛或语义猜测补字。
16. 图像中的阴影、描边与重复绘制可能被OCR识别成第二份文字。应先关联已知原生字形效果，再按内容与位置合并副本；保留原生标点和人工修改。文本框数增加不等于文字覆盖增加。
17. 用户指定保留的校徽、Logo及配套字样按一个完整标识登记，整体可移动，不要求拆解其中字形。其余普通文字逐项登记，不能用相邻大字或别处相同字符满足小字验收；没有完整标注分母时不报告覆盖率100%。
18. 图标、人物和连续艺术字不得默认按单字、偏旁、笔画或零件拆开。艺术字优先整词或整行的原生文本框；尚未验证字形与底层清除时保留完整素材并标为待校正，不能算文字恢复成功。本地或云端分割都只产生候选，确认属于同一对象的区域后合并成一个对象。用户明确使用画笔时按其选区操作，仍保留历史与原图。
19. OCR 单独输出横线、加号、箭头或其他纯标点符号时，置信度再高也不能据此从图标中挖走笔画。默认保留原素材并登记待确认；原生 PDF 的符号文字按原有文字证据处理，用户明确指定为文字的图片区域可继续校正。此规则不能把普通小标签、数字或未恢复的符号文字算作已完成。
20. 原生文字的局部间隙应核对源字符原点，不能仅拟合整行宽度或凭语义增加空格。多个格式片段必须仍属于一个完整文本对象。修改内容或字体时移除旧定位，撤销保留原始信息；诊断副本不得改正式页尺寸。只采用已实测的局部布局，后续失败不覆盖此前已验证的结果；原点误差、原生可编辑与实际外观分别验收。

21. 原生格式中保存的字距小数不代表渲染器实际精度。先测本机字体的间距台阶，用整行反馈约束累积误差；候选先过源原点误差门槛，再按相同物理裁剪与双倍率像素比较选取。未经实际渲染验证的方案及降分试验不得成为默认布局。
22. 换字体必须使用不同字体族，不能以微软雅黑与Microsoft YaHei等别名证明成功。保持内容和字号，真实Office保存重开后检查可见字形与缺字；空锚段的零字形字体记录不计为可见字体，合成粗体的重复绘制记录不计为新增源字符。

首轮模型检查使用当前会话模型直接读图。它属于本次会话的分析，不伪造一笔外部 API 调用，不计入产品云端账本。
