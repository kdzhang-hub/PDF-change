## 启动与安装

本机环境已安装时，双击 `启动.cmd`。第一次在新电脑安装，使用 Python 3.12 与 Node 执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File setup.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File setup-models.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File start.ps1
```

`setup-models.ps1` 下载约 2.5 GB 的 GPU 运行时与固定离线权重。运行时仅处理本地素材；OCR 与 SAM 已进行禁网测试。权重 SHA-256 在 models.lock.json 中，首次记录来自官方源下载，后续下载必须匹配。

Windows 的 Paddle C++ 接口不能读取部分中文模型路径，程序会在系统临时目录的 layerdeck-models 子目录镜像公开权重。用户文档与项目素材仍位于本项目 data 目录。

## 使用

上传 PDF 或 PNG、JPEG、WebP、TIFF、BMP 图片，选择页面、自动还原，然后在画布与右侧图层列表检查。可改字、拖动、旋转、调层级、组合、隐藏、锁定、撤销与重做。右上角“导出格式”可选择 PPTX 或 Word DOCX，均读取当前已保存的图层数据。图片原件保留，多页 TIFF 保持页序，JPEG 按 EXIF 方向处理。

右侧“图层”用于查找与筛选对象，“属性”用于改字、字体、字号及局部分层；选中图层后点击所选对象卡片即可进入属性，双击画布对象也可直接进入。位置与尺寸可按需展开。点击“专注画布”会收起两侧面板与工具栏，按 Esc 或“退出专注”返回；切换视图不会修改文档。标签页支持方向键及 Home、End 切换。

按最新要求，校徽、Logo 与配套校名字样作为完整标识保留原图，可整体选择、移动和缩放。独立素材中的部分徽章加字样可由本地规则识别，其他图标可在图片属性中点“保留完整标识”；需要拆分时可改为“作为普通素材处理”。恢复标识会一并移除从该图生成的自动文字副本，人工编辑或锁定的子对象受保护，保存历史可恢复。普通正文、标题、表格与小标签仍要求可编辑，标识不计入普通文字恢复分母。

DOCX 采用可移动的文字框、原生艺术字、图片与形状保留页面布局，支持文字渐变、描边、阴影及透明度。尚未重建连续正文、原始表格语义，复杂发光等效果仍需校正。已生成对象可编辑与全部原稿文字均已覆盖是不同验收项，未恢复内容仍需校正。

本机安装Word时，Word导出会对具有可见字形边界证据的自动艺术字测量字形，校准导出副本的位置、字号和字间距，保存的项目及PPTX布局不改变。原生PDF文字、手改、锁定、旋转与多行文字不按这类边界重排。Word环境不可用、字体缺失或测量不可靠时保留原位置并显示导出提示，不触发云端。

对图片素材可点选、框选、画笔拆分，或选择“本地识别此素材中的文字”。“查找完整对象”、点选和模型框选先生成只读候选；选择属于同一图标或同一段艺术字的区域后，点击“作为一个对象保留”，只生成一个完整对象。取消不会改变场景或历史；候选过期需重新查找。“保留整个选框”按完整矩形裁剪，不调用分割模型。画笔按用户明确涂抹的区域处理。文字识别后的字体、字色、位置和背景需校正；可恢复上一保存版本。原稿对照只用于检查，不导出为覆盖前景的底图。

默认自动还原不再直接采用未经确认的连通域或SAM碎片，大艺术字的多片OCR结果保留完整素材并标为待校正，避免把图标、偏旁或笔画当成多个对象。云端SAM也进入同一个完整对象确认窗口；没有确认不会直接改页。旧项目已有碎片不会自动覆盖，需要在保留历史的前提下恢复原素材或重新转换。

已还原为单行文字的艺术字可在属性中开启“随边框拉伸字形”，整词仍是一个原生文字对象，可改字、字体、字号及宽高；PPTX与DOCX使用同一份对象数据。自然排版仍为默认，多行文字采用自然排版。该能力不代表图片中的全部艺术字已自动恢复。

Word独立宽高修复：无渐变、阴影及额外字距的单行随框文字导出为一个Word原生艺术字对象，可整词改字、字体与字号。普通文字仍为文本框；含复杂特效或额外字距的随框文字保留现有文字框及效果，并显示Word横向字形适配未通过的提示。十页中英自制样本在真实PowerPoint和Word均通过改字、字体、字号保存重开；8个无特效宽度样本字形边界误差最大1磅。中文跨Office外观仍有差异，真实图片艺术字的全部自动恢复尚未通过。见deliverables/wordart-native-20261102/整词艺术字独立宽高修复实测.md。

普通 PDF 优先保留原生文字与路径。复杂裁剪、蒙版和混合效果按实际绘制动作提取独立透明素材；其中 PDF 特殊混合模式转换为当前位置下的普通透明表现，移动后需要复核效果。图片内部未拆完的对象明确保留为待处理。

## 当前限制

2026-10-29明确验收线：背景和装饰至少95%的可见语义对象能独立选择、移动、缩放与删除；可见文字100%能改字、换字体、调字号，包含艺术字、图片内文字和小标签。必须以原页面逐项标注清单计算覆盖率，并检查移动残影、背景补全及PowerPoint保存重开。提取出的文本框数量、碎片数量和SSIM均不能代替覆盖率。当前尚未达到这两项验收线；已知反例及未验证范围见deliverables/v3-movement-20261028/coverage-audit-20261029.json。

当前软件入口接受PDF与上述图片格式。PPTX曾作为测试参考及导出结果使用，尚未实现直接导入PPTX，不能把参考PPTX的测试计为PPTX导入能力。

所有普通文字（包括小标签、导航、页脚、艺术字与图内正文）必须能改字、换字体、调字号，才能通过完整验收；用户明确要求保留原样的完整标识除外。右侧可按文字和图片筛选图层，文本属性支持字体、字号、字间距、粗体与斜体。

2026-10-28 更新：本机安装 PowerPoint 时，网页自动转换会测量字形、校准文字位置与字间距；也可点击“校准文字”处理当前页。校准跳过手工修改、锁定、旋转与多行文字；失败时保留原位置并提示校正，不会转交云端。“待恢复”筛选列出部分已识别但尚未可靠重建的文字图片，手工校正框可带入 OCR 候选。它不是全部未识别文字的完整清单。

字号、内容、字体或字距改变后，文本框会按测量结果扩展，防止放大文字被裁掉。窄窗口可在“页面”“画布”“字体与图层”间切换。导出采用不可变场景快照和独立本地进程，生成独立文件，避免并行导出相互覆盖。

本地 OCR 未能正确识别时，选中图片，在“局部分层”选择“框选”，框住旧文字，再展开“小字识别有误？手工校正为文字”。输入正确内容、字号与颜色后，点击“清除原字并生成文本框”。旧文字区域会从残余图片清除，原素材保留；不透明区域的背景补全标为推断，需对照原稿核验。当前手工校正要求图片旋转为 0。

- 不保证图片中文字、艺术字、所有语义子对象都已经变成原生可编辑对象。
- 隐藏内容只能推断补全，不能宣称恢复原始隐藏数据。
- PDF 与 Office 的字体、插值、混合和导出压缩仍可能造成差异。
